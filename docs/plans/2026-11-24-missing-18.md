# 18 missing user actions (2026-11-24)

Tier T2 (deletion, personal data, migration). Founder: "now build the 18 missing ones".

## Decisions taken from the code
1. Health edit: `PATCH /api/agent/policies/:id/facts`. Writes the clients columns and the same facts inside
   report_data (insurer, expiry, premium, base sum insured) so the shared report and the book agree. Score and
   the report's words do not change, and the screen says so. A re-run reads the document again and replaces edits;
   the screen says so.
2. Change type: the rerun route takes `insurance_type`. The new type is stored only when the read succeeds; on
   failure the row returns to what it was. Costs the check or entry of the NEW type. Sharing is switched off.
   Rows without a document just change type.
3. Renew: upload with `?renews=<id>`; new row linked by `clients.renewed_from` (migration 040) and takes the old
   row's customer and contact. Old row is hidden from due lists. Without 040 the upload still works, unlinked.
4. Manual add: `POST /api/agent/policies/manual`. No read, no check. Paid plans only (the Free plan meters entries).
   Health without a document has no report: the page says so and offers nothing else.
5. Original PDF, WhatsApp draft and share off on the policy page (so phones get them).
6. Locked PDFs: unlocked in the browser, the password never leaves the device.
7. Life list: share popover.
8-10. Customer: DOB, call, WhatsApp, draft, upload, claim, claims list.
11. Duplicate warning by phone/email on add and convert; merge moves every row that points at the customer.
12. Convert moves lead policies (and files) to the customer.
13. Import (Excel/CSV) with duplicates skipped, export to Excel.
14. Renewals page: own customers tab, 30/60/90 days.
15. Claims: search, delete (files first), policy picker + policy number, `claims.client_id` (040).
16. Saved comparisons list, delete, open, attach customer.
17. Delete account in Settings (server route exists). Plan page shows data-entry reads left. No price exists for
    more reads, so it is a WhatsApp request, not a checkout: price is a founder decision.
18. Consumer photo upload and phone change.
